# RD.DEV — Personal Portfolio

Responsive dark-theme portfolio for Rupesh Dhole, built with plain HTML, CSS, and JavaScript.

## Features
- Mobile, tablet, and desktop responsive layout
- Dark developer-inspired visual design
- Animated role text and scroll reveal effects
- About, skills, projects, learning roadmap, and contact sections
- Links to GitHub projects; no framework or build step required

## Run locally
Open `index.html` in a browser, or run `python -m http.server 8000` and visit `http://localhost:8000`.

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your professional email.
2. Add your LinkedIn URL if desired.
3. Review skills and project descriptions to ensure they reflect your current work.

## Publish with GitHub Pages
1. Create a repository named `rd-dev-portfolio`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to its root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Your site URL will look like `https://rupesh7672.github.io/rd-dev-portfolio/`.
